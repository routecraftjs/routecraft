Logs the current exchange via the exchange logger and continues the pipeline unchanged. Defaults to info level. By default the logger prints id , body , and headers ; pass a formatter to log a derived value instead. // Log id, body, headers at info level . log ( ) // Log a derived value . log ( ( exchange ) => ( { id : exchange . id , body : exchange . body } ) ) // Log at a different level . log ( undefined , { level : 'warn' } ) Copy Use .log() for ad-hoc visibility inside a route.
