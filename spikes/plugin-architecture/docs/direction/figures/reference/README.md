# Reference figures

Figures supplied as a model for the direction figures, not figures of the
direction themselves. They are here for their form: a system drawn as named
boxes with labelled edges, a legend that says what each kind of edge means,
and one line under the picture that states its conclusion.

| File | What it shows |
|---|---|
| `every-way-in.png` | The harness from outside, supplied by Jaco as the visual identity for every direction figure. Recreated in the figure system as `every-way-in.tsx`; its middle band is opened up in `inside-the-harness.tsx`. |
| `one-runtime-every-way-in.png` | The harness a team runs: who calls it, the doors, what every capability gets out of the box, what it reaches and with which credentials. Supplied by Jaco as the format to follow for a figure of the architecture's internals. |
